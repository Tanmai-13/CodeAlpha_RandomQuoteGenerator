# CodeAlpha Random Quote Generator

A clean and responsive **Random Quote Generator** developed as part of the **CodeAlpha App Development Internship – Task 2**.

The application displays meaningful quotes with their authors and allows users to generate a new quote with a single click.

## Features

- **Random Quote Display:** Shows a quote when the application opens.
- **New Quote:** Generates a different quote with a button click.
- **Author Display:** Clearly displays the author of each quote.
- **Local Quote Dataset:** Includes 20+ meaningful quotes without relying on an external API.
- **No Consecutive Repetition:** Avoids displaying the same quote consecutively.
- **Smooth Transitions:** Includes simple animations when changing quotes.
- **Clean Interface:** Simple, modern, and user-friendly design.
- **Responsive Design:** Works on both desktop and mobile devices.
